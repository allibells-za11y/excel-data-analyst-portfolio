# Workplace Gaps — Professional Spreadsheet Practice
Applies to all Excel tier workbooks

## What this covers
- Microsoft Copilot for formula generation and validation
- Python in Excel (pandas, matplotlib via Azure cloud container)
- Real-time co-authoring via OneDrive and SharePoint
- Version history and file recovery
- Formula auditing: Trace Precedents, Evaluate Formula, Watch Window
- I-P-O workbook architecture (Input, Process, Output)
- Documentation standards: assumption logs, change logs, cell comments
- Power Automate flows (scheduled refresh, threshold alerts)
- Office Scripts (cloud-native VBA replacement)
- Workbook performance optimisation (volatile functions, ghost named ranges)
- Data storytelling and communicating findings to non-technical audiences
