# Tier 3 — Advanced Visualisation and Analysis
Dataset: Superstore Sales (Kaggle · 9,994 rows)

## What this covers
- PivotTables with calculated fields and grouping
- Slicers and Timelines connected to multiple PivotTables
- PivotCharts (bar, line, donut, combo)
- Charts and Graphs (5 types with professional formatting)
- Sparklines (line, column, win/loss)
- Goal Seek
- Scenario Manager
- Data Tables (1-variable and 2-variable)
- Executive Dashboard build
- Analysis ToolPak (descriptive statistics, regression, correlation)

## Key finding
18.7% of Superstore orders are loss-making, concentrated in the Tables
sub-category due to excessive discounting above the 12.5% profit margin.
