# Power BI Module 1 — Foundations and Data Preparation
Dataset: AdventureWorks Sales (Microsoft GitHub · 7 tables · 60,400 rows)

## What this covers
- Power BI Desktop interface and orientation (mapped to Excel equivalents)
- Import vs DirectQuery vs Live Connection — decision framework
- Connecting to multiple data sources with a FilePath parameter
- Privacy levels and when each applies
- Column Quality, Distribution, and Profile views in Power Query
- Data type correction, null handling, whitespace trimming
- Applied Steps — non-destructive audit trail
- Reference vs Duplicate queries
- Pivot and Unpivot columns
- Folder append — loading multiple files automatically
- Merge Queries (Left Outer JOIN) — building Sales_Enriched
- Query folding — which transformations push work to the source
- Star schema design: fact tables, dimension tables, surrogate keys
- Date dimension requirements and Auto Date/Time (disabled)
