# Power BI Module 3 — Report Design and Visualisation
Dataset: NHS England A&E Attendances and Emergency Admissions (england.nhs.uk · 12 monthly CSVs · 2023–24)

## What this covers
- Visual selection framework (12 chart types mapped to analytical questions)
- Format pane: every setting that matters (title, axes, labels, legend, gridlines)
- Conditional formatting (RAG — Red/Amber/Green against the 95% NHS 4-hour standard)
- NHS colour theme applied consistently across all visuals
- Custom tooltip pages showing trust performance mini-dashboard on hover
- Filter hierarchy: visual, page, report, and all-pages levels
- Slicer types: List, Dropdown, Tile, Relative Date, Between
- Slicer sync across multiple report pages
- Edit Interactions: Filter, Highlight, None — including National Benchmark card pattern
- Drill-through pages with keep-all-filters enabled
- Bookmarks and button navigation (Chart/Table toggle)
- Selection pane for tab order and visibility control
- AI visuals: Smart Narrative, Q&A, Key Influencers, Decomposition Tree
- Anomaly Detection and Forecast on line charts
- Grouping and Binning
- WCAG 2.1 accessibility audit (14-item checklist)
- Alt text, tab order, colour contrast compliance
- Mobile Layout view for phone consumption
- Paginated Reports: Power BI Report Builder, parameter-driven NHS formal return, PDF export

## Key NHS finding
In 2023–24, Type 1 A&E 4-hour performance averaged 71.4% nationally — 
significantly below the 95% NHS standard. December 2023 and January 2024
showed the worst performance, consistent with winter pressures.
