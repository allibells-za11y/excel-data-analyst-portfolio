## The four-layer learning stack

### Layer 1 - Microsoft Excel (Complete)
*From foundational formulas to business intelligence-level modelling*

| Module | Dataset | Key skills |
|--------|---------|------------|
| Tier 1 — Foundations | Product Sales · 1,000 rows | Data entry, SUMIF, conditional formatting, date and text functions |
| Tier 2 — Intermediate | IBM HR Analytics · 1,470 rows | XLOOKUP, INDEX/MATCH, SUMIFS, COUNTIFS, AVERAGEIFS |
| Tier 3 — Advanced Visualisation | Superstore Sales · 9,994 rows | PivotTables, dashboards, Goal Seek, Scenario Manager, regression |
| Tier 4 — BI Level | AdventureWorks · 60,400 rows | Power Query, Power Pivot, DAX, time intelligence, VBA, forecasting |
| Workplace Gaps | All tier workbooks | Copilot, I-P-O architecture, formula auditing, Power Automate |

**Key finding from Tier 3:** 18.7% of Superstore orders are 
loss-making, driven by discounting above the 12.5% profit margin — 
demonstrated through regression analysis and a one-page executive 
summary recommending a discount cap policy.


### Layer 2 - Power BI (In progress)

| Module | Dataset | Key skills |

| M2 — Data Modelling | Contoso 100K · 100,000 rows | Relationships, DAX, CALCULATE, time intelligence, calculation groups, Performance Analyzer |

**Key finding from M3 (NHS A&E):** Type 1 A&E 4-hour performance 
averaged 71.4% nationally in 2023–24 against a 95% target. December 
2023 and January 2024 showed the worst performance — identified through 
anomaly detection, Key Influencers analysis, and a formal paginated 
report output built in Power BI Report Builder.
